# Shipment Logistics Management System Frontend

Modern full-stack frontend application for Shipment Logistics Management System using React + TypeScript + Vite + Tailwind CSS.

---

# Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Axios
- React Hook Form
- React Hot Toast
- Lucide React Icons
- Context API
- JWT Authentication

---

# Features

## Authentication
- JWT Login/Register
- Token stored in localStorage
- Axios Bearer Token Interceptor
- Protected Routes
- Role Based Access

## Roles

### Admin
- Dashboard
- Manage Shipments
- Approve/Reject Shipments
- Assign Employees
- Manage Employees
- Manage Clients

### Client
- Dashboard
- Create Shipment
- View My Shipments
- Edit/Delete Shipment

### Employee
- Dashboard
- View Assigned Shipments
- Update Shipment Status
- Add Remarks
